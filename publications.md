# Publications

A selection of research and technical work spanning radar imaging, digital signal processing and embedded systems.

---

## Research Publications

### DSP Based Sliding Spotlight SAR Processor

Research work on a DSP-based processor architecture for high-resolution Synthetic Aperture Radar imaging.

Key areas included:

- Sliding Spotlight SAR processing
- DSP-based architecture
- Signal-processing algorithms
- Processor and memory requirements
- Real-time / near-real-time processing considerations

---

### COTS Multiprocessor DSP Configuration for Real / Near Real Time SAR Processors

Technical work exploring commercial-off-the-shelf multiprocessor DSP architectures for real-time and near-real-time Synthetic Aperture Radar processing.

Key areas included:

- Multiprocessor DSP architecture
- Parallel signal processing
- SAR processing requirements
- Computational and memory considerations

## Academic Research

### DSP-Based Motion Estimation for MPEG-2 / MPEG-4

Academic research involving the implementation and evaluation of motion-estimation algorithms for MPEG-2 and MPEG-4 video processing using DSP-based platforms.

The work focused on:

- Motion-estimation algorithms
- DSP implementation
- Algorithm optimization
- Computational efficiency
- Image-quality evaluation
